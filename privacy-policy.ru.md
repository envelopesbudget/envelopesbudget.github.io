# Политика конфиденциальности

**Приложение:** Envelopes: Мой бюджет (Android)
**Разработчик:** Ivanov Oleg
**Контакт:** support@envelopesbudget.org
**Дата вступления в силу:** 11 сентября 2026

## Коротко

Приложение не имеет собственного сервера. Ваши финансовые данные хранятся
на вашем устройстве и, если вы сами это включите, в вашем личном облачном
хранилище. Разработчик не получает, не хранит и не обрабатывает эти данные —
у него нет технической возможности их увидеть.

Приложение не содержит рекламы, не использует аналитику и не передаёт данные
третьим лицам для маркетинга.

## Какие данные обрабатывает приложение

Всё, что вы вводите сами: счета, операции, суммы, категории, получатели,
заметки, планируемые платежи, цели и — по вашему желанию — фотографии чеков.
Эти сведения хранятся в базе данных на вашем устройстве.

Приложение **не запрашивает** и не собирает: имя, адрес, номер телефона,
контакты, список установленных приложений, идентификаторы для рекламы,
данные о местоположении.

## Где хранятся данные

**На устройстве.** Основное хранилище — база данных в защищённой области
приложения. При удалении приложения эти данные удаляются вместе с ним.

**В вашем облаке — только если вы подключите его сами.** Приложение умеет
синхронизировать бюджет и складывать резервные копии в один из сервисов:
Google Drive, Dropbox или сервер WebDAV. Данные передаются напрямую между
вашим устройством и вашим аккаунтом в этом сервисе. Разработчик в этой
цепочке не участвует и доступа к файлам не имеет.

Для Google Drive приложение использует ограниченный доступ (`drive.file`):
оно видит только те файлы, которые создало само, и не может просматривать
остальное содержимое вашего диска. В Dropbox приложение работает в
собственной папке и не имеет доступа к прочим файлам.

**По локальной сети.** Есть режим прямой передачи между двумя вашими
устройствами по Wi-Fi. Данные идут напрямую, минуя интернет и любые серверы,
и шифруются одноразовым кодом подтверждения, который вы вводите вручную.

## Шифрование

Если вы зададите пароль (раздел «Бэкапы» в приложении), им шифруется **всё,
что уезжает в ваше облако**: резервные копии, фотографии чеков и файл
синхронизации бюджета. Используется AES-GCM с 256-битным ключом, который
выводится из пароля функцией PBKDF2.

Пароль хранится только на вашем устройстве в защищённом хранилище системы
Android и никуда не передаётся — ни разработчику, ни в облако. **Если вы
забудете этот пароль, расшифровать файлы невозможно** — ни вы, ни
разработчик не сможете этого сделать.

Без заданного пароля эти файлы лежат в вашем облаке в открытом виде. Файл
синхронизации при этом сжат (обычный gzip) — это сделано ради экономии
мобильного трафика и защитой не является.

### Формат зашифрованного файла открыт

Ваши данные не должны зависеть от одной программы, поэтому формат описан
здесь, и знание его защиту не ослабляет: стойкость держится на пароле, а не
на скрытности формата.

Файл начинается с четырёх байт `MB2E`, за ними 16 байт соли, 12 байт nonce,
шифротекст и 16 байт GCM-тега. Ключ — PBKDF2-HMAC-SHA256, 600 000 итераций,
256 бит; шифр — AES-GCM-256. Зная пароль, такой файл можно расшифровать
любым инструментом, поддерживающим эти стандартные алгоритмы. Файлы,
начинающиеся с `MB1E`, — тот же формат более ранней версии со 100 000
итераций; приложение по-прежнему их читает.

Внутри расшифрованного файла синхронизации может оказаться gzip — его
распакует любой архиватор, а внутри лежит обычный JSON.

Проще всего это делает само приложение: «Бэкапы» → меню ⋮ → **«Сохранить
читаемую копию»**. Пункт снимает и шифрование, и сжатие и отдаёт обычный
файл, который можно открыть чем угодно.

Передача по Wi-Fi между устройствами также шифруется; ключ выводится из
шестизначного кода подтверждения, и сам код в сеть не отправляется.

## Разрешения и зачем они нужны

| Разрешение | Для чего |
|---|---|
| Интернет | синхронизация с облачным хранилищем, которое вы подключили |
| Камера | фотографии чеков и сканирование QR-кодов |
| Микрофон | голосовой ввод операции (распознавание выполняет система Android) |
| Доступ к файлам | сохранение и чтение резервных копий, импорт и экспорт |
| Биометрия | разблокировка приложения отпечатком или лицом |
| Уведомления | напоминания о запланированных платежах |
| Локальная сеть | прямая передача данных между вашими устройствами по Wi-Fi |

Приложение не запрашивает разрешение на определение местоположения.

Голосовой ввод использует системный сервис распознавания речи Android.
Обработка произнесённой фразы выполняется средствами операционной системы и
подчиняется политике конфиденциальности поставщика этой системы.

## Сторонние сервисы

Приложение обращается только к тем сервисам, которые подключили вы:

- **Google Drive** — [политика конфиденциальности Google](https://policies.google.com/privacy)
- **Dropbox** — [политика конфиденциальности Dropbox](https://www.dropbox.com/privacy)
- **WebDAV** — сервер, который вы указали сами; его условия определяет его владелец

Ни один из этих сервисов не получает данные от разработчика — только от вас
и по вашей инициативе.

## Платежи

Если в приложении появятся платные возможности, оплата будет проходить
средствами Google Play. Платёжные данные обрабатывает Google; разработчику
они не передаются. Разработчик получает от Google Play только сведения о
факте покупки, необходимые для предоставления доступа.

## Дети

Приложение не предназначено для детей младше 13 лет и не собирает данные о
них осознанно.

## Ваши права и удаление данных

Данные принадлежат вам и находятся под вашим контролем:

- удалить данные с устройства — удалите приложение или воспользуйтесь
  функцией сброса в настройках;
- удалить данные из облака — удалите папку приложения в вашем Google Drive,
  Dropbox или на сервере WebDAV;
- забрать данные — приложение умеет выгружать резервную копию файлом,
  экспортировать операции в CSV, а зашифрованный или сжатый файл из облака
  превращать в обычный («Сохранить читаемую копию», см. раздел
  «Шифрование»).

Запрос на удаление разработчику направлять не требуется: у разработчика
ваших данных нет.

## Журнал ошибок

Приложение ведёт технический журнал событий синхронизации и ошибок. Журнал
хранится только на устройстве, никуда не отправляется автоматически и виден
вам в настройках. Если вы решите прислать его для решения проблемы, это
произойдёт только по вашему явному действию.
